## Hey there! 👋

I'm **Proof**, a 21-year-old self-taught developer from Romania.

I'm mostly interested in **C++, graphics programming, and game engine development**. I love figuring out how things work behind the scenes, especially when it comes to rendering pipelines, GPU architecture, and low-level engine systems.

I enjoy building things from scratch, experimenting with different approaches, and occasionally spending way too much time optimizing something that already works.

My main tech stack includes **C++, C#, Vulkan, HLSL, and GLSL**. I mostly work with Visual Studio, CMake, and Git, although I'm always open to exploring new tools and technologies.

A lot of my time goes into developing custom engine technology, researching modern rendering techniques, and experimenting with ideas that might eventually turn into something bigger.

I'm particularly interested in **real-time graphics, hybrid rendering, performance optimization, and engine architecture**.

I also enjoy game development itself, from gameplay systems to experimenting with different mechanics and technical ideas.
